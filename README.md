# 🌌 Orion Browser

**Orion** is a modern, lightweight, cross-platform web browser built from scratch using **Python** and **PyQt5 (QtWebEngine)**.

---

## ✨ Features (Current Progress)

- 📑 **Multi-Tab Architecture:** Open, switch, and close multiple tabs smoothly.
- 🔍 **Smart Navigation & Search:** Direct URL input with integrated Google Search fallback.
- 📜 **Local History Storage:** Automatically logs browser history into persistent `history.json`.
- ⭐ **Bookmarks System:** Save your favorite websites locally with a single click.
- ⚡ **Lightweight & Fast:** Optimized memory footprint using Chromium rendering.

---

## 🛠️ Tech Stack

* **Language:** Python 3.x
* **GUI Framework:** PyQt5 / QtWebEngine
* **Storage:** JSON File System
